# Commercial Systems Journey

Single public site repository for the progression from market intelligence and constraint diagnosis into technical integration, GTM execution, measurement, proof, and career leverage.

## Site map

- `/` — canonical journey + current proof
- `/roadmap.html` — 12-week forced-output roadmap
- `/systems.html` — executable commercial systems stack
- `/shipping.html` — artifact-to-shipper map
- `/proof/*` — six current proof families
- `/method/reality-os.html` — Reality OS / Work Actualization method
- `/downloads/execution-proof-operating-system.xlsx` — execution and evidence workbook

## Claim boundary

The site distinguishes artifact existence, reproducible verification, deployment, external interaction, operational outcomes, and economic outcomes. No KPI or adoption claim is made unless supported by recorded evidence.

## Deploy

This is a static site. Deploy the repository root directly on Netlify or GitHub Pages. Vercel also works as a static deployment.
