# Route Warm Access

## Goal
Turn an existing relationship plus current proof into one concrete next interaction.

## Output
```yaml
person_or_org:
known_relationship_state:
current_relevant_proof:
value_to_them:
next_interaction:
ask:
receipt_sought:
risks_or_unknowns: []
```

## Rules
- Use only verified relationship history.
- Optimize for workflow access, technical inspection, referral, meeting, pilot, hiring conversation or introduction.
- Do not fabricate warmth, prior promises, interest, availability or influence.
- Prefer giving a useful artifact/observation before asking for broad help.
- One next interaction only.
