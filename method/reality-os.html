Method / provenance layer

Reality OS + Work Actualization

A manual-first operating model for turning observations into evidence, decisions, actions, outcomes and inspectable proof—then using repeated manual traces to discover what infrastructure deserves automation.

The loop

Reality → signals → evidence/context → hypothesis → constraint → decision → action → state transition → outcome → measurement → updated reality

Work Actualization compiler

RAW WORK → EXTRACT → NORMALIZE → ATOMIZE → SELECT USER/JOB → SELECT CHEAPEST SURFACE → PACKAGE → VERIFY → EXTERNALIZE → MEASURE → INGEST RESPONSE → UPDATE SOURCE WORK

Why manual first

Entities, states, exceptions and automation boundaries are not frozen from imagination. Real workflows reveal repeated entry, transformation, lookup, routing, failure and decision patterns. Only demonstrated repetition becomes software infrastructure.

Truth types

Observed / executed

Direct source/system state or irreversible action with evidence.

Claimed / reported

A person/source says it; not independently verified.

Inferred / hypothesized

Interpretation or model that still requires a falsifying test.

Methodology is not presented as a standalone impact result.
